# Security scope

This is a reviewed portfolio export, not a production security certification. Use the isolated demo first. Never connect this export to an existing production database: schema initialization is intended for a new dedicated database. Keep the server on localhost unless you have independently reviewed authorization, uploads, API error disclosure, data retention, outbound request handling and provider settings. SMTP success does not prove delivery. Timers and cooldown are in memory; queue selection is not an atomic claim. Do not run multiple send workers without addressing idempotency and locking. The original behavior auto-queues generated drafts; mandatory human approval is not guaranteed. External discovery installation and original deployment automation are omitted. No production environment, credentials, personal resumes or customer records are included.
